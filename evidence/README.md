# Evidence

This directory holds the test evidence that the advisories in the forks' `SECURITY-BACKPORTS.md`
cite: build manifests, harness results and logs, grouped by kind and date
(`evidence/<kind>/<YYYY-MM-DD>/`). Each file records one run as it happened; the advisories name
the file and its date. Files are added, never edited: a new run gets a new file or a new date.
